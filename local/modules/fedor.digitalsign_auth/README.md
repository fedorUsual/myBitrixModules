### Описание модуля
Модуль реализует авторизацию в публичной части сайта через цифровую подпись вместо стандартной авторизации по
логину/паролю или LDAP-авторизации.
При входе на сайт, происходит сканирование цифровых подписей, имеющихся на устройстве пользователя, из них в окне
авторизации необходимо выбрать ту, под которой будет осуществлен вход на сайт.

### Особенности работы модуля
Модуль подходит для коробочной версии Bitrix.  
Перед установкой модуля необходимо убедиться в том, что на сервере установлено расширение для php "phpcades". В
противном случае скрипт будет возвращать ошибку.  
Кроме того, из-за особенностей работы плагина Криптопро работа модуля может быть некорректной при использовании
браузера Google Chrome.  
Модуль затрагивает только авторизацию в публичной части. В административной части авторизация остается по логину и
паролю.  
При после авторизации в меню административной части появляется пункт со списком сертификатов пользователей портала 
(Сервисы -> Федор: Авторизация через КриптоПро -> Сертификаты пользователей). 
Этот список нередактируемый и не поддерживает удаление элементов, можно лишь открыть запись о сертификате для 
подробного изучения.

### Инструкии по установке.
#### Настройки сервера
Для работы модуля на сервере, где располагается сайт, должно быть установлено расширение phpcades. Для этого нужно 
скачать его исходники и собрать на сервере. Инструкция и ссылки на документацию имеются на официальном [сайте 
КриптоПро](https://docs.cryptopro.ru/cades/phpcades/phpcades-install).  
Модуль поддерживает работу с PHP версии 8.3 и выше, поэтому перед установкой необходимо убедиться в его наличии.

#### Настройки персонального компьютера для авторизации через модуль

1. Для работы с КриптоПро на персональном компьютере клиента должны быть установлены инструменты работы с электронными 
подписями от КриптоПро, такие как: 
   1) КриптоПро CSP. 
   2) Расширение браузера. 
Инструкция по их установке расположена на [сайте КриптоПро](https://docs.cryptopro.ru/cades/plugin/plugin-installation-windows).
   
2. После установки запустите на своем компьютере программу "Инструменты КриптоПро":
   1) На вкладке "Общее" введите лицензию.
   2) На вкладке "Сертификаты" найдите сертификат с электронной подписью, который вы планируете использовать для входа 
   на сайт и проверьте срок ее действия.

#### Настройки портала необходимые для установки и работы модуля
1. Для установки модуля необходимо чтобы в настройках Главного модуля, во вкладке Авторизация, для основного сайта 
   была установлена форма соглашения о персональных данных.

После этого модуль готов к работе.
